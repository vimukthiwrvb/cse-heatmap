CSE Budget 2027 Heatmap

1. Windows: double-click start.bat.  Mac or Linux: double-click start.command (needs Python 3).
   The heatmap opens in your browser at http://localhost:8765/
2. Open data.xlsx in Excel and edit the Companies or Measures sheet.
3. Save. The heatmap redraws within about 4 seconds. No button to press.

Keep all files in this folder together. The "Read me" sheet in data.xlsx explains each column.
Do not open index.html by double-clicking it: browsers block a page opened that way from reading data.xlsx.

Online version (GitHub Pages)
The heatmap is also published at https://vimukthiwrvb.github.io/cse-heatmap/
- Anyone with the link can see it and download data.xlsx.
- It does not update live. To change it: edit data.xlsx, then commit and push to GitHub.
  The site refreshes within a minute or two.
